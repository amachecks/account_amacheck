AMACheck — Mail Vendor Checks from Odoo

What it does

AMACheck turns an Odoo vendor payment into a printed check mailed to your vendor by first-class mail — no printing, no envelopes, no postage.

Key Features

  • One-click Send Check on any outbound vendor payment.
  • Prepaid eChecks — buy bundles and track your balance in Settings.
  • Duplicate protection — the same payment is never mailed twice, even if you click again.
  • Transaction log with live mail status for every check.
  • Clear error messages that tell you exactly what to fix and where.

Configuration

  1. Go to Settings > AMACheck, enter your License Code and click Refresh Balance.
  2. Open your bank journal (Accounting > Configuration > Journals) and set the Signer and Next Check Number.
  3. Make sure the journal's bank has its 9-digit routing number in Bank Identifier Code.

Requirements

  • An AMAChecks license code (amachecks.com).
  • Odoo 18 or 19 with Accounting (Invoicing).
  • A bank journal with account number, routing number and your company address.
