AMACheck — Send Vendor Checks by Mail

Powered by Online Check Writer

What it does

AMACheck connects Odoo vendor payments to the Online Check Writer API so you can mail physical checks to your vendors directly from Odoo — no manual data entry, no printing, no postage.

Key Features

  • One-click Send Check — send a mailed check from any vendor payment form.
  • Sandbox / Production toggle — test safely before going live.
  • Automatic payee sync — vendor address details are synced to AMACheck on every send.
  • Automatic bank account sync — your bank journal is registered with AMACheck automatically.
  • Duplicate protection — prevents accidentally sending the same check twice.
  • Detailed error reporting — clear messages tell you exactly what is missing and where to fix it.

Configuration

  1. Go to Accounting > Configuration > Settings > AMACheck.
  2. Enter your AMACheck API Key.
  3. Select Sandbox for testing or Production for live checks.
  4. On your bank journal, click Sync AMACheck Bank Account to register your bank.

Requirements

  • An active Online Check Writer account and API key.
  • Odoo 17.0 with the Accounting module installed.
  • Bank journal with a bank account, routing number, and address configured.
